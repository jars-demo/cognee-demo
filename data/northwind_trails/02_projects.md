# Northwind Trails: projects

## Project Summit

Project Summit adds offline navigation to TrailMate, so hikers can follow a trail without a signal.
It depends on the offline maps service maintained by Ravi Patel and on offline mode in the Android
app built by Tom Becker. Sofia Alvarez is the project lead. The target launch is spring.

## Project Riverbend

Project Riverbend shows live trail conditions, such as closures and mud warnings, inside TrailMate.
It uses the nightly data pipeline built by Lena Fischer. Maya Chen sponsors the project.
Riverbend is blocked until the park rangers' data feed switches to the new format.
